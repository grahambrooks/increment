# Homebrew formula

`increment.rb` lands here, generated by `scripts/release.py formula` and merged by
the `finalize` job in `.github/workflows/release.yml` (release-kit v2), pinned to
the checksums of the archives that release actually uploaded. It is not written
by hand.

The formula is kept in this repository rather than in a separate
`homebrew-increment` tap, so the tap needs an explicit URL:

```sh
brew tap grahambrooks/increment https://github.com/grahambrooks/increment
brew install increment
```
