# Homebrew formula

`gdiff.rb` lands here, generated by `.github/render-formula.py` and committed by
the `formula` job in `.github/workflows/release.yml`, pinned to the checksums of
the archives that release actually uploaded. It is not written by hand, and
nothing lives here until the first tag is cut.

The formula is kept in this repository rather than in a separate
`homebrew-gdiff` tap, so the tap needs an explicit URL:

```sh
brew tap grahambrooks/gdiff https://github.com/grahambrooks/gdiff
brew install gdiff
```
